# Как выложить сайт на свой домен

## Вариант 1. VPS с Ubuntu (рекомендую)
1. Купите домен и VPS с Ubuntu 22.04 или 24.04. Запишите IP-адрес сервера.
2. В настройках домена (DNS) создайте две записи типа **A**: `@` и `www`, значение: IP сервера. Подождите от 10 минут до пары часов.
3. Загрузите папку проекта на сервер, например в `/opt/novo-tours`.
   - С Windows: программа WinSCP или команда `scp -r novo-tours-site root@IP:/opt/novo-tours`
4. Подключитесь к серверу по SSH и выполните:
   ```bash
   cd /opt/novo-tours
   bash deploy/setup.sh ВАШ-ДОМЕН.ru ваша@почта.ru
   ```
   Скрипт сам поставит всё нужное, запустит сайт и бота и выпустит бесплатный HTTPS.
5. Если на сервере нет файла `.env`, скрипт создаст его. Впишите в `/opt/novo-tours/.env` токен бота и chat id, затем:
   `systemctl restart novo-site novo-bot`

Проверка: откройте `https://ВАШ-ДОМЕН.ru`, отправьте тестовую заявку.

Логи: `journalctl -u novo-site -f` и `journalctl -u novo-bot -f`
Заявки также сохраняются в `/opt/novo-tours/leads.jsonl`.

## Вариант 2. Виртуальный хостинг с Python (Beget, Timeweb)
В панели хостинга создайте сайт на Python/Passenger, загрузите файлы проекта в папку сайта, укажите файл запуска `passenger_wsgi.py`, установите пакеты из `requirements.txt`. Бота (`bot.py`) на таком хостинге обычно запустить нельзя, но заявки с сайта в Telegram всё равно приходят: для этого бот не нужен.

## Как обновлять
Поменяли `tours.py` или картинки на своём компьютере: загрузите изменённые файлы на сервер и выполните `systemctl restart novo-site`.
