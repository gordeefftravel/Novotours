# Данные сайта

Источник правды — JSON-файлы. После правки запустите `python3 tools/build.py` и закоммитьте результат (GitHub Pages публикует готовый HTML).

## Новая страна
Создайте `data/countries/<slug>.json` по образцу любого существующего (обязательные поля проверяет build.py) и добавьте slug в список `order` в `tools/build.py`, если нужен порядок. Фото: положите `static/img/<имя>.jpg`, запустите `python3 tools/optimize_images.py` (создаст WebP) и укажите `"img":"<имя>.jpg"`. Без фото показывается градиентная обложка.
Раздел `practical`: ставьте `visa_checked` (дата) ТОЛЬКО после проверки по официальному источнику — иначе на странице автоматически выводится предупреждение «не проверялось».
Заведения: список `food.places` [{n, addr, map}] заполняйте только проверенными реальными адресами.

## Статья журнала
`data/blog/<slug>.json`: slug, title, desc, category (одна из 8 рубрик в build.py), published, updated, sections [{h, p[]}], links [[текст, url]], countries [slug].

## Отзывы
`data/reviews.json` — массив [{name, text, trip}]. Пока файла нет, блок «Отзывы» на главной скрыт. Добавляйте только настоящие отзывы с согласия авторов.
